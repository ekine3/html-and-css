    What is Flatpak?

    Is an independent from distribution package manager aiming to function in separated environments allowing it to work in different systems.



    Flatpaks are all-in-one packages that do not depend on other external packages, are installed at user level, they can be installed in a sandbox and work for plenty systems.

    How to install Ungoogled Chromium using Flatpak

    Ungoogled Chromium is a lightweight approach to the browser removing Google web service dependency, retains default Chromium experience and enhances privacy control and transparency. For these and other reasons, this time I'll install the application in a Majaro Linux system using Flatpack.

    We can run the installer from the terminal, in this instance I was using Xfce Terminal Emulator, calling the application by just typing its moniker flatpak. Now, to know how to use the package manager we can search for documentation online or running:
    flatpak --help
    We will see the usage syntaxis.

    Now we will run a package search over Flatpak's repositories, using the "search" option:
    flatpak search chromium
    We'll see Packages that match the description of our search, the name of the package, the application id, their branch and repositories.

    In this case, I want to install the package "Ungoogled Chromium", to see more information about a specific package we can use the "info" option. We'll see a prompt with some useful information like the ID of the package, its version, the size, license, architecture among some more details:
    flatpak info io.github.ungoogled_software.ungoogled_chromium

    After a view of the package description and information, we can install the package by using the "install" option. We will have to approve it's installation after a few confirmations, and we will see again infomation about the permission the package will ask to other programs, the state of the download and installation and check list of the steps completed; after that we will a final confirmation of the installation of the package.
    flatpak install io.github.ungoogled_software.ungoogled_chromium
