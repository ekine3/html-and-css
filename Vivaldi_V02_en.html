    What is Vivaldi?

    Vivaldi is a web browser from Norway available since 2015 and still constant updates. It is customizable, user friendly, it support themes, is configurable, privacy focused and has distraction free options. Recently it was one of few projects that stated on AI as an option, not a default integration like many other browsers.

    Vivaldi is available for many systems like Windows, Mac, Android, iOS and many for many Linux ditributions and package managers.

    Installing Vivaldi in Windows (traditional method)

    To install Vivaldi we can go to their page "Downloads" page. There we can find by default installers for Windows 10+, MacOS, Linux and links for Google Play and Mac's App Store.
    Download Vivaldi.

    As an example here we got the installer for MacOS, it was an Apple Disk Image with a .dmg extension around 250MB os size; and the windows installer about 160MB in size in an .exe file.

    Wizard

    In Windows we can execute the installer and we will see a Wizard for its installation where we can accept Terms and conditions, to share crash reports, specify destination folder, language and installation type.

    After some screens we will have the application installed in our system.

    Installing Vivaldi in Windows using winget

    To install this browser in Windows 11 using winget we first need to search for the package moniker.
    winget search vivaldi


    For this case we'll use the package ID "Vivaldi.Vivaldi", to show the manifest of the package, license, version and description we can use the show option.
    winget show Vivaldi.Vivaldi

    After we decided the pacakge to install we can use install option to the package ID.

    Using Vivaldi

    After we completed the installation of the browser we will see the browser Welome Tour with 9 steps (if you choose more configuration more steps to configure will be necessary) to show customization, configurations and an overview of the whole application.

    First step

    In the first step of the tour we'll see options for keyboard use: meaning visual zoom and animation, caret browsing, single key shortcuts, UI focus control and webpage focus. Also we'll have the option to hare crash reports with the developers. In this case we won't active either of the options.

    Second step: vivaldi account

    We have the option to sing on for a Vivaldi account, for Proton VPN, for Vivaldi social at Mastodon, to sync configuration, to log into forum and to share themes. In this case we also skip the step.

    Third step

    We have the option to add Vivaldi to our Desktop taskbar, to set it as our default browser this would open links and MIME types associated automatically, and import history, password and bookmarks from other browsers. We'll also skip this step.

    Fourth step: adblocker

    Now we will have by default adblocker and analytics blocker enabled by default in the browser. This is one of the most usefult and covenient integration of the browser, even most users will eventually configure themselves the blockers rules, I recommend to new users to saty with basic protection in order to display without problems most popular websites. After some use and progress and depending on the user's proficiency we can make stronger configurations.

    Fifth step: Style

    Now we can select the broswser style, in some modern browsers like Zen Browser the "Vertical left" style is very popular, and for older browsers we commonly have the "Simple" style. In order to have easy acces to other Vivaldi integration we will select "Classic" style.

    Sixth step: Theme

    By default we have 4 themes, and the browser can follow system preferences. Vivaldi offers theme customization a really cool feature for many users. For personal taste I will select "Dark theme".

    Seventh step

    The browser has in the "Classic" style a Tools Panel, that provide quick access to bookmarks, reading list, downloads, history, notes, windows and tabs, translation and sessions; we can even add more tools. For this example we'll disable/untoogle all the tools.

    Eight step

    In the panel we can also have a designated subpanel for websites. The Web Panel allow us to have organized social media, messengers, news and streaming service in one place. By default we have access to Reddit, Spotify and a Thesaurus services; in this example we will skip this step.

    Nineth step

    The browser also offers a Mail, Calendar and feeds client, similar in fuctionality to Thunderbird or QuiteRSS. In specific I found Vivaldi's RSS intergration really simple to teach to other users, it require reading less documentation and less understanding of OPML, XML and RSS files and applications. In this example we won't configure right now this fuctionality, so we'll skip this step.

    Start Browsing

    After this tour, we can star browsing the internet. We can retrigger the tour at V (the icon on top of the browser) - Help - Vivaldi Welcome Tour

    RSS in Vivaldi

    As previously stated I found that for some users it is difficult to get in touch with the "RSS" whole as a concept. One of the many challenges lay into using a different application or program to see and filter syndication pulls. To reduce the use of external programs I realized the RSS integration in Vivaldi is quite simple and easy to show.

    To begin, we have to enable RSS feeds as a productivity feature. Go to V - Settings or use the shortcut Ctrl+F12 to show the "Vivaldi settings: General".


    Then go to the bottom of the left Panel "Feeds" and toogle the "Enable feeds" box.

    After enable the Feeds, we'll see configuration options like feed detection, messages per view, filter buttons, message counters and more. We can

    There are many ways to add new feeds to the client. For this example we will use an "OPML" file (Outline Processor Markup Language) that contains several feeds, previously gathered and organized in other RSS feeders.

    Download this file: feedsV08.opml

    Once you have the file downloaded in your local system, you can load it to the browser.

    To go to V - File - Import from Applications or Files, and the "Imports menu" will appear.

    Click in the "Imports" combox and select "Feeds (OPML file)".

    After we select the file to be imported we will have the option to select the file to import, in this case we'll use the OPML file provided in this example.

    Once we successfully loaded the OPML filem we will get a screen with a all the Feeds to be loaded, their name, address, refresh interval and the "Feeds" widget option. We just need to click over the "Add feeds" option and them will be loaded in the Browser.

    We will see the Feeds in the left panel and syncronization notifications will be deployed. We successfully loaded the feeds and we can look for News and updates in a consistent and easy way.
