    When we work with API's in Rest, we need to manipulate resources through HTTP methods, each method has a clear and specific purpose.

    Definition

    The HyperText Transfer Protocol works to navigate websites and also define actions a client can do over the resources from a server.
    These actions are mapped thorough HTTP methods:

  • GET: retreives information.

  • POST: creates a new resource.

  • PUT: updates a complete resource.

  • PATCH: partially updates a resource.

  • DELETE: deletes a resource.


    • All these actions make the comunication between APIs REST intuitive and predictable.

    GET

    GET is used to retreive data form a server.

  • Secure: does not make changes in the server.
  • Idempotence: is the property of certain operations whereby they can be applied multiple times and without changing the results.


    • Example of request
    We will use the public API JSON Placeholder:
    GET https://jsonplaceholder.typicode.com/users/1
    Response in JSON
    {
    "id":1,
    "name": "Leanne Graham",
    "eamil": "Sincere@april.biz"
    }

    Is useful to request resources /users or to obtain a specific resource /users/1.

    POST: create a new resource

    The POST method is used to create a new resource in the server.

  • Not idempotence: every time we execute it generates a new resource.


    • Example with cURL (create a post):
    curl -X POST https://jsonplaceholder.typicode.com/posts ^
    -H "Content-Type: application/json" ^
    -d "{ \"title\": \"Hola Mundo\", \"body\": \"Este es un ejemplo\", \"userId\": 1 }"

    Json response:
    {
    "id": 101,
    "title": "Hola Mundo",
    "body": "Este es un ejemplo", "userId": 1 }
